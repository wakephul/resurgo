# Marchio di Resurgo

## Il logo

È una r minuscola con il braccio alzato, come la fenice di "Post fata resurgo". Il braccio ricorda il collo della fenice e anche una lingua di fuoco. Si legge come una r anche a 16 pixel (guarda `logo/resurgo-icona-16.png`).

| File | Quando usarlo |
| --- | --- |
| `logo/resurgo-r-rosso.svg` | su fondo bianco o chiaro, il caso normale |
| `logo/resurgo-r-nero.svg` | stampa a un colore, timbri, documenti in bianco e nero |
| `logo/resurgo-r-bianco.svg` | su fondo rosso, nero o su foto scure |
| `logo/resurgo-icona.svg` | icona dell'app, favicon, avatar di GitHub (r bianca su quadrato rosso) |
| `logo/resurgo-readme.svg` | README di GitHub, diventa più chiaro da solo con il tema scuro |
| `logo/favicon.ico`, `logo/resurgo-icona-*.png` | favicon e icone già pronte da 16 a 512 pixel |
| `logo/resurgo-r-rosso-512.png` | la r rossa in PNG, per dove l'SVG non va |

Il segno va usato così com'è: niente ombre, niente sfumature, niente contorni, niente rotazioni. Nel testo il nome si scrive con l'iniziale maiuscola: Resurgo.

## Colori

| Nome | Codice | Dove |
| --- | --- | --- |
| Rosso fenice | `#C4311B` | logo, selezione, focus, pulsante principale. Contrasto 5,5:1 sul bianco, va bene anche per il testo |
| Inchiostro | `#141414` | testo, logo a un colore |
| Cenere | `#5E5E5E` | testo secondario (6,5:1 sul bianco) |
| Linea | `#DCDCDC` | separatori, bordi delle finestre |
| Pannello | `#F2F2F2` | pannello e barre laterali |
| Bianco | `#FFFFFF` | fondo delle finestre |

Tema scuro: fondo `#161616`, testo `#EDEDED`, testo secondario `#9A9A9A`, rosso `#FF6B4F` (6,4:1 sul fondo scuro).

Il rosso si usa poco: una cosa rossa per schermata, al massimo due.

## Carattere

Noto Sans per tutto: interfaccia, sito, documenti. È libero (licenza OFL), la famiglia Noto ha una versione per quasi ogni scrittura e resta leggibile anche sugli schermi a 1024×768 dei portatili vecchi. Noto Sans Mono per terminale e codice.

## Tentativi scartati

In `prove/` ci sono le versioni scartate e gli script che le hanno disegnate: la fenice a pixel sembrava un'aquila da stemma, la piuma una penna, la fiamma un fornello.

I colori come variabili CSS sono in `colori.css`.
